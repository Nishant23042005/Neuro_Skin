🩺 NeuroSkin
AI-Powered Intelligent Skin Disease Detection & Care Platform

🌟 Overview

NeuroSkin is an advanced AI-powered dermatology assistant that helps users identify potential skin diseases from uploaded images using Deep Learning and Computer Vision.

The platform goes beyond simple image classification by combining:

✨ AI disease prediction
✨ Symptom-based refinement
✨ Severity analysis
✨ Personalized medicine recommendations
✨ Emergency risk alerts
✨ Professional PDF reports

Built with a modern full-stack architecture using React, Flask, and TensorFlow, NeuroSkin delivers an intelligent and user-friendly healthcare experience.
